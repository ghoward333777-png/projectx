2Claims kept, but corrected to what the specification supports

Your mid-review instruction was to correct errors without cutting content, so each of these claims stays in the draft, reworded to the defensible form the overview itself uses. "Cannot hallucinate" and "ungrounded assertions are structurally impossible" now read as the overview's structural-groundedness guarantee: an ungrounded assertion is structurally unavailable to the generation process, because the permissible output vocabulary is constrained to terms traceable to specific Fact Units — a stronger and more precise claim than an absolute that invites challenge. "Structurally incapable of harming humans" became "structurally constrained against causing harm," with all six supporting mechanisms retained and the measurable trial architecture added as evidence. "Does not rely on transformer embeddings" was qualified, because the overview specifies that each Fact Unit carries an embedding representation and that the ingestion domain is the sole location of any trained component; the corrected text says no answer rests on statistical generation, which is the claim that is actually true. "Becomes more stable as it grows because atomic universes naturally stabilize with size" conflicted with the specified capacity ceiling — a first-order phase boundary at which retrieval states disappear discontinuously — so stability at scale is now attributed to its engineered sources: energy-descent convergence, the conservative operating ceiling, and the elective unique-equilibrium regime. "Replaces GPU-heavy matrix computation… yielding cost savings" was restated as the architectural difference, with a sentence noting that specific compute-cost comparisons are deliberately not asserted, matching the overview's stated practice of citing only claims traceable to specified mechanisms. "Probable questions… saved and used forever" now carries the invalidation rule: a pre-computed answer is invalidated upon revision of any contributing record, so a served answer is never stale. "Self-evolving and capable of autonomous conceptual growth" was reframed as conceptual growth within the knowledge substrate under the non-bypassable human gate, since the overview makes every self-improvement finding a proposal requiring a named human's approval. And the broad brain analogies — edges as axons, exceptions as inhibitory microcircuits, "a functional analog of the brain," the hippocampus and prefrontal-cortex parallels — were kept as plain-language analogies but placed explicitly outside the five claimed correspondences, because the overview's Drafting Record deliberately declined to carry the brain-region mapping table and admits correspondences only under the Chapter 101 methodology.

3Flags — your decisions before adoption Flag

Six terms in the draft name things the current overview does not. Each is retained in the reviewed document, grounded to the nearest specified mechanism where one exists, but each needs either a specification entry or a rename before this text can move into the provisional application.

Atomic Universe Layer

The draft's second foundational layer — particles as data atoms, bonds as semantic relationships, quantum transitions as inference leaps — appears nowhere in the overview. The nearest specified mechanism is the physical-constraint layer (§53.9): registered constraints with closed-form residuals, tolerances, SI units, and applicability predicates, under which an impossible completion is excluded at any score. The reviewed draft presents the layer through that specified mechanism while keeping your framing. Decide: specify "Atomic Universe Layer" as its own subject matter, or adopt it as informal narrative for §53.9.

Skill Inventory Layer · Meta-Learning Layer · Adaptive Schema Engine · Memory Consolidation Cycle

None is named in the overview. The Memory Consolidation Cycle partially maps to specified consolidation (concept formation gated by a consolidation count; long-term concept consolidation). The other three are new. Decide: add them to the specification or mark them as future work in any adopted text.

Neuro-Symbolic Integration Layer · Hypergraph Reasoning Layer · Concept Compression Layer

The functions exist under specified mechanisms — hyperedge-granularity convergence, the worldview hypergraph, noise elimination and abstraction — but the layer names are new. Decide: register the names as terminology or restate using the specified mechanism names.

Brain-Grade Knowledge Engine · Biological Cognition Parallel Architecture

Both are used as proper names in the draft and neither appears in the overview. They read well as product language; they are not yet specification terms. Decide: keep as marketing vocabulary only, or register them.

Semantic audio/video compression and media colorization

"Storing meaning rather than pixels" and "colorize historical media" have no specified mechanism. The nearest is attractor stabilization (§36), which permits reconstruction only marked as reconstruction, confidence-bounded, and inadmissible as grounding. The reviewed draft keeps both claims and attaches those constraints, which is the form in which they are defensible. Decide: whether to specify these as extensions before any adopted text relies on them.

Forecasting scope

"Stock-market analysis" was retained under the specified forecasting discipline: subjects restricted to institutions, systems, and organisational processes; individual natural persons refused; projected-future results carry credible intervals and are never admitted as records. If consumer-facing stock advice is intended, that is a scope change the specification would need to address.
