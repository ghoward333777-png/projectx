Network memory

The relationships between QueryBook's agents are a layer of memory. Specialists whose facts answer a question together, and harvesting agents that succeed together, form synapses; repeated success strengthens them, joint failure weakens them, unused ones fade and are removed. Strongly bound agents form assemblies; assemblies linked through their members form networks of networks; each kind of problem keeps its engram — the agents that were active when it was solved. Answers are never changed by this: it records, adapts and explains.

synapse → agents → assembly → linked assemblies → network memory

Assemblies

Agents bound by strong synapses (strength ≥ 0.5, about five joint successes).

Networks of networks

Assemblies linked by synapses between their members.

Engrams

For each kind of problem, the agents active when it was solved.
