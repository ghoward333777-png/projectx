How the studio makes a video

  • Action shots use a stored clip of the action when there is one (seconds), re-shaped, re-timed and re-coloured here. Only an action with no stored clip is generated by the video model, once; it is then stored for reuse.
  • Voice-over on an action shot is spoken by Language Builder with its voices and its pronunciation resolver (heteronyms like read, lead, wind). If the speech is longer than the action, the last frame is held.
  • Narrator shots are an author persona from Language Builder saying the text, in a video made by Gemini (HeyGen when Gemini cannot), or by HeyGen or D-ID with the persona's own voice. Nothing animates a face on this computer. The finished narration is stored, so the same narrator saying the same text again costs nothing.
  • Joins get in-between frames when the two ends are similar; otherwise a cut. Captions come from the word timings Language Builder measures.
  • Every result is checked: motion kept in each shot, lip-sync length unchanged, sound and picture the same length, upscaled picture still matching its source.
  • Start Language Builder first (START-ALL starts every program). Action shots without voices work without it.
