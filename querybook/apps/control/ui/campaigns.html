Directives

A directive is a Word (.docx), Markdown (.md) or text file with a task register: a table whose first column holds task ids like MED-01, with the task and its tier (T0 / T30 / SM). A focus directive — a document with a Sector table and a recommended first move, no task register — refines the open campaign: its tasks are re-ranked so the focus leads every wave. Directives placed in the Control Panel's directives folder are set up automatically (files named Focus… refine).
