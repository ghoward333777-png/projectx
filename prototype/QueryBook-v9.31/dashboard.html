LLM Providers live

Any subscription or local server. OpenAI-compatible (OpenAI, Groq, Together, Ollama/llama.cpp with /v1) or Anthropic. Paste your key to store it locally in your store folder, or leave it blank and set the named environment variable (more secure). The key is never shown back in the page and is only sent to the provider's API. After adding, press Test to make one live call and see the exact result.

Language Phase 2 no longer needs an LLM. Semantic grounding is now fully deterministic — a bundled public-domain dictionary plus self-grounding against your store — so you can learn English end to end with no API key at all. An LLM here is optional, only for the smarter chat/extraction layer. If you do add one: it uses the Anthropic API, which needs an API key from console.anthropic.com (starts with sk-ant-, credits under Plans & Billing) — a claude.ai chat subscription is not an API key. Press Test to see exactly whether a key works.
