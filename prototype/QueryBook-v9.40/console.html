How QueryBook learns language before it understands any

QueryBook begins with a sequence of deterministic preprocessing and semantic-extraction tasks that run before it understands any human language. These give it structure, grammar, entities, and relations — the scaffolding on which "understanding" can later happen.

Takeaway

Seven stages carry raw text from shape → rules → objects → atoms → coordinates → geometry → ability. Each stage is mechanical and inspectable; none of them requires the system to already know English, Spanish, French, or any other language. Tap any component below for a guided drill-down.

A recurrence template is an event structure that repeats on a fixed cadence — the same actors doing the same thing with the same result, only the instance changing. Because it recurs and is attested by many sources every period, its Fact Units are cheaply corroborated and cover the timeline completely. That redundant backbone becomes the scaffold on which the unique facts of each instance are located and filled in.

Lay one strand per day for 2,500 years — ≈913,106 days from ~475 BCE to today. The deterministic backbone of reality (calendar arithmetic, astronomical cycles, math identities) is generated by rule, so it fills the entire span by computation — that alone is ~5.48M true, verifiable Fact Units. Contingent history then accretes onto the strand, modern era first, building around the redundant recurrences.

QueryBook · Universal Fact Content Substrate (UFCS) — pre-understanding pipeline reference.

Fact Units (FUs) are atomic subject–predicate–object records anchored to their exact location in the source. The stages above describe how text is decomposed into those units and integrated into the semantic graph before any question is answered.
