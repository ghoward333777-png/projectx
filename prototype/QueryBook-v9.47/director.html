Scene Director — QueryBook → Gemini Omni adapter

QueryBook is the director: a structured scene graph. Gemini Omni is a prompt-driven renderer. This adapter turns stage, lighting, camera, blocking and timeline into exact Gemini prompts — pure deterministic templating (no model in the loop, so it is covenant-safe). Video rendering is optional, gated on a Gemini key, and never fabricated.

FU graph→SceneGraph→PromptBundle→ Gemini Omni→Compliance→Edit prompts↻

1 · FU graph (meaning)

Edit the QueryBook FU graph, or load the worked example (a two-character noir dialogue in a small LA bar).

🔑 Gemini / Veo video key

Paste your Google Gemini API key (with Veo access) to render real video. Stored only on this computer; never committed. Without it, Render returns a dry-run plan.

2 · Gemini prompt bundle

The exact text the adapter would send to Gemini Omni.

3 · Scene graph & render trace

The deterministic SceneGraph (and, on render, the Gemini payload / dry-run plan).


      
    

  


  

    
⚖️ Covenant: prompt generation is deterministic templating — no LLM asserts anything.
