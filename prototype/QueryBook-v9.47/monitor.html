Database health & self-repair

The knowledge index is checked continuously. A corrupt (“malformed”) index no longer breaks the menus — QueryBook quarantines it and rebuilds from your blocks (the source of truth) automatically. You can also force a rebuild here.

Data preservation & backup

Your knowledge is copied to a second folder on your drive at every launch, and any differing copy is snapshotted aside before it is refreshed — so data is never lost. Optional off-site copies go to Google Drive, Bunny.net and OVH Cloud.

Email alerts to the sys admin

Emails a digest — fail alerts, error codes, and application logs — on a schedule (hourly by default). Credentials are stored only in a local, private file and are never shared. Gmail: use an App Password (Google Account → Security → App passwords) with host smtp.gmail.com port 587.
