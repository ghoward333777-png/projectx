1. Books, Publishing & Long-Form Works
Document type	Typical elements
Book	Title, author, copyright/front matter, table of contents, introduction/preface, chapters, sections, figures/tables, notes, references, appendices, index
Booklet	Cover/title, introduction, short sections, illustrations, instructions/information, contact/resource information
Monograph	Title, abstract/overview, focused thesis, chapters, evidence, citations, bibliography
Textbook	Units, chapters, learning objectives, explanatory text, examples, figures, exercises, summaries, glossary, references, index
Reference book	Organized entries, definitions/facts, cross-references, citations, indexes
Handbook	Topic-based sections, procedures, recommendations, reference material, appendices
Manual	Purpose, requirements, procedures, warnings, diagrams, troubleshooting, references
Guidebook	Overview, categorized guidance, recommendations, instructions, maps/data/resources
Workbook	Instruction, exercises, prompts, worksheets, examples, answer areas
Encyclopedia entry	Subject heading, overview, factual sections, references, related entries
Dictionary entry	Headword, pronunciation, definitions, usage, etymology, examples
Anthology	Editor's introduction, individual works, author information, notes
Biography	Subject background, chronology, life events, achievements, interpretation, sources
Autobiography	First-person chronology, experiences, reflection, supporting material
Memoir	Selected experiences, narrative episodes, reflections, thematic development
E-book	Book structure plus hyperlinks, metadata and potentially multimedia/interactivity
Rich-media book	Text, images, audio, video, charts, interactive questions, forms, simulations and linked resources

For QueryBook specifically, I would treat rich-media books as their own document class, rather than merely considering them electronic books.

5. Reports

This should similarly become a major superclass.

General report

Purpose, scope, methodology, findings, analysis, conclusions, recommendations, appendices.

Business report

Executive summary, business problem, background, methodology, findings, analysis, recommendations, financial/operational implications.

Annual report

Organization overview, leadership commentary, activities/performance, financial information, risks, governance and outlook.

Progress report

Objective, reporting period, completed work, current status, obstacles, metrics, upcoming work.

Investigation report

Mandate, allegations/issues, methodology, evidence, interviews/records, findings, conclusions.

Incident report

Incident identification, time/place, involved parties, factual description, consequences and follow-up.

Audit report

Scope, standards/criteria, testing, findings, exceptions, conclusions/opinion.

Inspection report

Object/site inspected, criteria, observations, deficiencies, photographs/evidence, recommendations.

Evaluation report

Program/object evaluated, criteria, methodology, evidence, results, conclusions.

Feasibility report

Proposal, requirements, alternatives, technical feasibility, operational feasibility, economics, risks, recommendation.

After-action report

Event/objective, intended outcome, actual outcome, successes, failures, lessons learned, corrective actions.
