# Schema

## features.json — array of 279

| field | type | notes |
|---|---|---|
| `id` | int | 1-based, stable within a version, **not** stable across versions |
| `name` | string | unique |
| `category` | string | User-Facing, Internal, Admin |
| `citation` | string | Chapter or section in the specification |
| `chapter` | int or null | Parsed from citation |
| `actor` | string | Who invokes it; "internal" where no external actor |
| `function` | string | Usually mirrors name |
| `algorithm` | string | Prose statement of what the function does |
| `rule` | string | The governing computational or structural rule |
| `worked_expression` | string or null | Spreadsheet notation; evaluates |
| `lean_statement` | string or null | **Unverified.** Reference only |
| `domain` | string | D0-D14 with name |
| `layer` | string | Governance (vertical), Knowledge, Reasoning, Experience, Platform |
| `module` | string or null | Derived cluster hint, format `D4.ch52` |
| `has_expression` | bool | Convenience |

## claims.json — array of 341

| field | type | notes |
|---|---|---|
| `id` | int | Contiguous 1-341 |
| `type` | string | independent or dependent |
| `depends_on` | int[] | Always length 0 or 1; multiple dependency is a defect |
| `text` | string | Full claim text |
| `length` | int | Characters |

## domains.json — array of 15

`id` (D0-D14), `name`, `layer`, `mandate`, `feature_count`.

## transfer_matrix.json

`from`, `to`, `permission` (permitted / denied / conversion), `guarantee`.
`*` is a wildcard. A pair absent from this file is **denied**.

## paths.json

`paths[]` with `name`, `sequence`, `note`; plus
`intersection_of_query_and_ingestion` and the two `invariants`.

## excluded_set.json

`subsystem`, `reason`. No internally-generated proposal may modify any of these.

## manifest.json

Computed counts and integrity results. Regenerated by `validate.py` logic;
do not hand-edit.
