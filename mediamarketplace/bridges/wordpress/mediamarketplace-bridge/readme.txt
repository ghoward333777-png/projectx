Embeds your MediaMarketplace Studio store in WordPress and signs visitors in with one click.

== Description ==

MediaMarketplace Studio is a self-hosted server that sells and protects digital media. This
plugin connects a WordPress site to it. WooCommerce is not required.

1. In the MediaMarketplace server admin, open Bridges and add this site.
2. In WordPress, open Settings > MediaMarketplace and paste the server URL, site ID and secret.
3. Place [mms_showcase] on a page. Use [mms_signin] to let logged-in members open their media.
